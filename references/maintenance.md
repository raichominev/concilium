# Documentation and example maintenance

Generalize each war story before it enters the public repository. Every example must be
self-contained and judgeable from its own text, without figures, table names or artifacts that
can be verified only inside the origin project's private repository.

The origin project keeps full-detail originals in its own documentation and syncs the generic form
here. Contributor pull requests adding examples follow the same rule.

Keep release notes summarized and reader-relevant. Put operational detail in `SKILL.md` or the
relevant reference page, then link to it from the README.
